# Digital Product Factory

Use this shared workflow to turn existing capability into an original buyer outcome and a validated offer. Read the canonical playbook before recommending a build:

`$SECOND_BRAIN\Workflow\30 - Resources\Playbooks\Digital_Product_Factory_Playbook.md`

For a deep reference teardown and candidate product ladder, also read:
`$SECOND_BRAIN\Workflow\30 - Resources\Research\Motion_Prompt_Manual_Teardown_And_Empire_Application_2026-10-01.md`

Recall existing capability and monetization records first. Route creation to the relevant installed format-specific skills; this skill coordinates the product and commercial decisions rather than replacing document, design, video, research, pricing, legal, or growth specialists.

When packaging a repeatable method, prefer the reference manual's proven shape: mental model -> decision architecture -> structured inputs -> production output -> worked example -> controlled iteration -> troubleshooting -> quality gate. Adapt the labels to the domain; never copy the supplied manual's wording, prompts, worksheet, examples, scorecard, title, or visual identity.

The output is either the playbook's five-part opportunity brief or, for an approved build, the full product brief, specialist handoffs, QA gate, delivery package, and ready-to-list copy draft. Mark evidence as E1/E2/E3, validate demand before full production, preserve source/derivative rights, and never publish, contact buyers, charge, or make a guarantee without explicit user authorization.
