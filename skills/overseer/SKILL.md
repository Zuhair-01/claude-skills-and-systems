# OVERSEER — routing map + library search

Two layers. **Teams** = live, in context, always available. **Library** = ~2800 skills + 137 agents on
disk at 0 context cost, reached by search below.

Teams are a **starting map, not a fence**. A task outside every team is normal and expected — that is
what the library is for. Unbuilt projects will need skills never triggered before; they are already on disk.

## Step 2 — nothing live fits? Search the library

That is the normal case, not a failure. Most of the collection is **not in your context listing** —
absence from the teams above means **nothing** about whether a skill exists. Search before concluding.

Search when:
- Task names a SaaS/tool/platform you see no live skill for (Twitch, Xero, Notion, Airtable, Shopify…)
- Task is in a domain the live teams don't cover (Drupal, GIS, healthcare, game dev, Chinese platforms…)
- You are about to write from scratch something that smells common
- Before answering "there's no skill for that" — that sentence requires a search first

```bash
python3 ~/.claude/overseer/search.py <terms...>                 # keyword search (ranked)
python3 ~/.claude/overseer/search.py --cats                     # all categories + counts
python3 ~/.claude/overseer/search.py --cat <cat> --list -n 40   # browse a category
python3 ~/.claude/overseer/search.py <terms> --cat <cat>        # search within a category
```

- Ranking is rarity-weighted: a distinctive term (`xero`, `drupal`) beats a generic one
  (`accounting`, `api`). Two terms beat one: `search.py stripe refund`.
- `--kind agent` / `--kind skill` to restrict. `--all` includes live items (hidden by default —
  they're already in your context). `-n N` for more hits.
- Output gives a `-> path`. **That path is the payload.**

### Then use it

**Skill hit** → `Read` the `SKILL.md` at that path and follow it. A skill is just instructions;
it does **not** need to be installed to work. Do not copy it anywhere. Just read and follow.

**Agent hit** → `Read` the `.md`, then spawn:
`Agent(subagent_type: "general-purpose", prompt: <the agent's body> + "\n\n---\n\nTask: " + <the task>)`
Library agents are not registered, so `subagent_type: "<library-agent-name>"` will **fail**.
Passing its body as the prompt is the working path.

### Promote (make it permanent)

If an item earns its place — used repeatedly, or clearly core to an ongoing project:

```bash
python3 ~/.claude/overseer/promote.py <name>            # library -> live
python3 ~/.claude/overseer/promote.py --demote <name>   # live -> library
```

Promotion costs context every session (~5 tok/skill, ~60 tok/agent), so promote on evidence of
repeat use, not on a hunch. Takes effect next session. Nothing is ever deleted.

### Maintenance

After adding, moving, or editing skills/agents by hand:
```bash
python3 ~/.claude/overseer/build_index.py
```
